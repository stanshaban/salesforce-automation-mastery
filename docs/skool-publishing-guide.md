# Publishing the lessons in Skool

The portal is the complete reading experience. Each lesson also has a downloadable Markdown text file, and each path has one combined file.

## Files to use

- `public/lesson-exports/J01.md` through `J28.md`: Junior.
- `public/lesson-exports/M01.md` through `M34.md`: Middle.
- `public/lesson-exports/S01.md` through `S25.md`: Senior.
- `public/lesson-exports/JR01.md` through `JR11.md`: Job Research.
- `docs/agentforce-lesson.md`: the standalone Agentforce project.
- `public/lesson-images/<lesson ID>.jpg`: a separate generated cover for each lesson, including `AF-L01.jpg`.
- `public/course-images/`: Junior, Middle, Senior, and Job Research classroom covers.
- `docs/image-prompts/`: the exact prompts used to generate the artwork.

## Transfer a lesson

1. Create or open the intended lesson in the Skool classroom.
2. Add the matching cover image. Keep the title as editable text rather than embedding it in the image.
3. Transfer the lesson text, headings and lists in readable sections.
4. Use Skool's quote formatting for the marked callouts. If pasted Markdown remains literal text, apply the formatting in the editor and remove the `>` characters. Automatic Markdown-to-rich-text import is not assumed.
5. Keep code in a code block if supported by the editor. Otherwise link to the full portal lesson or the corresponding source file so indentation remains reliable.
6. Preview the lesson on desktop and mobile, checking spacing, code, image crop and source links.

## Callout language

> **💡 Key idea**
>
> A short explanation that helps the learner understand a mechanism.

> **⚡ Try it**
>
> One concrete action with an observable result.

> **⚠️ Watch out**
>
> A specific limitation or likely mistake, followed by what to do about it.

> **🔎 Check your understanding**
>
> A question or observation that lets the learner test the explanation.

Use callouts where they add meaning. Do not turn every paragraph into a quote. The downloadable text includes self-check answers; if you want learners to attempt the questions first in Skool, place the answers after a clear divider or in a separate follow-up lesson.

The current work prepares text and images for publishing. It does not create or alter lessons in the Skool account automatically.
