## 02 · Start from the work

> 🎬 ЭКРАН. Раздел «Start from the work». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Anna needs to read vehicles and contacts, create test-drive requests, and edit appointments she is allowed to manage. She does not need to delete the vehicle catalogue or configure user accounts. Write the required operations before opening a permission editor. This provides a business reason for each grant. A permission set is a collection of permissions assigned to users. It generally adds to permissions already granted by the profile and other assignments. It is not a subtraction mechanism. If a profile grants Delete, leaving Delete unchecked in a new permission set does not remove that existing grant. Inspect the combined access rather than treating one configuration page as the entire user.

Create a permission set named SAM Appointment Editor. For this exercise, grant Read on Vehicle and Contact, and Read, Create, and Edit on Test Drive. Do not grant Delete, View All Records, Modify All Records, or broad administrative permissions. Configure the required field visibility and editability for Vehicle__c, Customer__c, Scheduled_At__c, and Status__c on Test Drive. Auto-number and other system fields are not ordinary editable fields, so do not force them into an identical editability checklist. For Vehicle, allow the fields Anna needs to choose a vehicle, including Model. Decide explicitly whether this exercise requires VIN visibility. Lookup selection also depends on access to the referenced records; a visible relationship field does not make the entire related object available.
