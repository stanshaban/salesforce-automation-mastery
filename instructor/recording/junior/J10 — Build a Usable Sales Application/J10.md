## 03 · Distinguish the page from the stored information

> 🎬 ЭКРАН. Раздел «Distinguish the page from the stored information». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A page layout arranges fields and actions for a record. A Lightning record page arranges components around that record. These configuration layers affect presentation. Field-level security controls access to a field. Removing a field from a layout is not a substitute for denying access, because another supported entry route may still expose an accessible field. The course Test Drive has an automatically generated Name, displayed as a number such as TD-0001. Anna should not be expected to type that number. Place Vehicle, Customer, Scheduled At, and Status where she can understand them. If you added the duration extension in J08, explain it alongside the calculated end rather than presenting the formula as another editable input.
