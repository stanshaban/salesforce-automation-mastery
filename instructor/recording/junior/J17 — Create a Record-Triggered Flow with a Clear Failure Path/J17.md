## 02 · Define the event and the business action

> 🎬 ЭКРАН. Раздел «Define the event and the business action». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A Flow is a configured sequence of operations. A record-triggered Flow starts when an eligible record is created, updated, or deleted, according to its configuration. Our requirement is deliberately small: when a new Requested Test Drive with a scheduled time is created, create one Task for its owner to follow up. A Task is a Salesforce work item. Creating it is not the same as sending an email or displaying a timed desktop reminder. Choose an after-save record-triggered Flow because it creates a separate related record. A before-save flow is useful for certain changes to the triggering record itself, but that is not this action. Limiting the trigger to record creation prevents an ordinary later edit from creating another Task. This is a specific duplicate-prevention design, not a universal guarantee against duplicate source appointments.
