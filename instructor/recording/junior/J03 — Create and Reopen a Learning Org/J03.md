Trailhead is Salesforce's learning website. It contains explanations and exercises. A Trailhead Playground is a Salesforce org intended for hands-on learning. Signing in to Trailhead opens the learning website; launching a Playground opens Salesforce itself. They are connected experiences, but they are not the same screen or the same set of stored information. For this lesson you need a browser and a way to sign in to Trailhead. You do not need Visual Studio Code, a terminal, or programming experience. We introduce those tools when they have a purpose. Use a personal learning environment rather than an employer's working org, and use fictional customers. Northstar is an invented company, not an account you need to obtain from someone else.

Close the Salesforce tab and launch the same Playground again from Trailhead. Check the selected environment name before launching. Two environments may look almost identical, so visual similarity alone is not sufficient evidence. Record the environment's friendly name and the route you used to reopen it in a private learning note. A Salesforce username and a contact email can be different. Do not guess credentials or publish them in an assignment screenshot. Trailhead provides a separate lesson for obtaining Playground credentials when a later tool requires them. For today's browser route, successfully reopening the selected org is the important result.
