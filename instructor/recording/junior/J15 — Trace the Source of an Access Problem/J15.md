Anna reports that Max cannot see an appointment. Begin by asking which user, which record, which fields, and which action. Record the route through the application and the exact visible result. 'Missing from Recently Viewed' and 'access denied when opening a known record' are different observations. The first may concern a list; the second is stronger evidence about record access. Use fictional records and private identifiers in the investigation note. Include the time of the check and the configuration changes that occurred shortly before it. A problem that started after a permission-set assignment is a useful clue, but timing alone does not prove the cause. Treat it as a hypothesis to investigate.

## 03 · Inspect grants before adding them

> 🎬 ЭКРАН. Раздел «Inspect grants before adding them». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Open the relevant user in Setup and inspect View Summary where available. The User Access Summary consolidates useful permission and assignment information. Access Granted By can show which profile, permission set, or permission set group supplies a particular permission. Refresh the summary after assignment changes and remember that not every possible access feature is represented in one screen. For missing object Read, inspect all object grants. For a field issue, inspect field permissions and the page configuration separately. For a record issue, inspect ownership, OWD, hierarchy settings, group memberships, sharing rules, manual shares, and broad record-access permissions. The checklist narrows the cause; it does not justify changing every item.

Prepare a missing-object case, a missing-field case, and a missing-record case in a controlled learning setup. Change one relevant assignment or sharing condition per case. If your org has too few users, execute the cases sequentially with a restricted test identity and restore the documented baseline between them.
