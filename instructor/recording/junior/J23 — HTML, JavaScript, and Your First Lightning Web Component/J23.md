HTML describes the structure of a web interface. A paragraph uses a p element; a list can use ul and li elements. Elements have opening and closing tags, and attributes describe additional information. A Lightning Web Component, or LWC, combines an HTML template with JavaScript behaviour and a metadata configuration file. It is not an Apex class running in the browser. JavaScript stores values and responds to events in the browser. A string is text, an array is an ordered collection written with square brackets, and an object groups named values inside braces. The sample row { id: 'demo-1', label: 'City EV appointment' } is an object in browser memory. It is not automatically a saved Salesforce record. The strict equality operator === compares values without the same coercion behaviour as loose equality.

## 03 · Read the component contract

> 🎬 ЭКРАН. Раздел «Read the component contract». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

import loads a named capability from another JavaScript module. The class extends LightningElement so it can participate in the LWC framework. A property such as state stores the current display state. A method such as showSample runs when its button is clicked. A getter, written with get, derives a value from current properties without being called with parentheses in the template. The template uses curly-brace bindings such as {isLoading} to read JavaScript properties. lwc:if, lwc:elseif, and lwc:else select the visible branch. Keep the branches adjacent. The list directive repeats markup for each row, and key supplies a stable identity for each rendered item. Do not use an array position as the meaningful identity of a changing business record.
