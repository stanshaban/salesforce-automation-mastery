## 02 · Read the language one construct at a time

> 🎬 ЭКРАН. Раздел «Read the language one construct at a time». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Apex is a programming language used on the Salesforce platform. A variable names a value, and its type describes what kind of value it can hold. Integer represents a whole number, String represents text, and Boolean represents true or false. An assignment such as Integer minute = 600 stores a value. A comparison such as minute == 600 asks a question; the two operations are different. A class groups related code. A method is a named operation with inputs, a return type, and a body between braces. public makes the method available to callers allowed by the language; static lets it be called on the class without creating an instance. return supplies the result. An if statement chooses a branch, and a for loop repeats a block for elements in a collection. Semicolons finish statements, while braces group their bodies.

## 03 · Choose a collection for a purpose

> 🎬 ЭКРАН. Раздел «Choose a collection for a purpose». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A List keeps elements in an indexed sequence and can contain duplicates. A Set keeps unique elements without promising a useful display order. A Map connects unique keys to values, such as an appointment ID to a prepared label. These choices express different needs; replacing every list with a map does not automatically make code better. Our example uses minutes after midnight as a simple integer exercise. 600 means 10:00 and 840 means 14:00. This is not a complete scheduling model: it has no date, time zone, duration, or vehicle. The function removes occupied values, ignores invalid or missing numbers, removes duplicates, and returns the remaining minutes in ascending order. Those decisions are explicit parts of its contract.
