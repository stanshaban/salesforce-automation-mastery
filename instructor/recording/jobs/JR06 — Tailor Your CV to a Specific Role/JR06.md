## 02 · Tailoring starts with the job, not with synonyms

> 🎬 ЭКРАН. Раздел «Tailoring starts with the job, not with synonyms». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Tailoring means helping a reader see the relevant parts of your existing experience. It does not mean rewriting your history to match every requirement. Begin with one verified job description and your master CV. Extract the three or four responsibilities that appear central to the role. Keep practical conditions, essential technical requirements and preferences distinct. Imagine a role focused on Apex integrations and LWC maintenance. Your master CV contains a test-drive form, a mock callout exercise and unrelated earlier software work. The form and callout deserve more space than an unrelated visual design experiment. You still need to label the callout as a training exercise if that is what it was.

## 03 · Map each priority to the strongest available evidence

> 🎬 ЭКРАН. Раздел «Map each priority to the strongest available evidence». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Create a small table: employer responsibility, your evidence, CV location and unresolved gap. For “maintain LWC,” point to a component where you can explain data flow, loading and error states. For “support production integrations,” a mock exercise is partial preparation, not proof that you have owned production incidents. Keep that gap visible in your preparation notes. Prefer an exact technical term when it accurately describes your work. If you used Queueable Apex, name it instead of saying only “background work.” Do not insert a technology merely because the description contains it. A keyword without a supporting example can create an interview question that exposes the mismatch.

## 04 · Use AI as an editor with a boundary

> 🎬 ЭКРАН. Раздел «Use AI as an editor with a boundary». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

An assistant can compare two supplied documents and propose clearer wording. Tell it to preserve employers, dates, ownership, technologies and measurements. Ask for changes with reasons so that you can review them. If it suggests a new accomplishment, reject the suggestion unless you have independent evidence for it. Review the output line by line against the master CV. Pay particular attention to subtle upgrades: “practised” becoming “led,” “training org” disappearing, or “supported a developer” becoming “architected the solution.” These changes may sound polished but alter the meaning. The final file is your representation of your experience, so you must understand and approve every claim.

## 05 · Save a version you can reconstruct

> 🎬 ЭКРАН. Раздел «Save a version you can reconstruct». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Save the tailored CV with the employer, role and date in your private application records. Record the source job description and the actual submitted file. You may later need to explain a project that was highlighted in that version. Keeping the file prevents confusion between several similar applications. Finish with a consistency check: dates match the master, links work, the summary fits the role and no essential context has vanished. Then decide whether the application is worthwhile given the remaining gaps. A tailored CV can make a real match clearer; it cannot create experience that you do not yet have.
