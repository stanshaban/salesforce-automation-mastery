Northstar adds Booking_Reference__c to store the scheduling provider's stable reservation reference. The field is a proposed extension to the starter, not existing metadata. Old appointments do not yet have values, old clients do not send the field, and some new provider responses arrive while migration is running. ## 04 · Make migration restartable and race-aware

> 🎬 ЭКРАН. Раздел «Make migration restartable and race-aware». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A restartable backfill can continue after interruption without corrupting records already processed. Use stable selection and business identifiers, record progress, and define what qualifies as completed. Do not rely only on a remembered page number if the underlying set changes during the run. Concurrent writes matter. If a new booking obtains a current reservation reference while the backfill holds an older snapshot, the backfill must not overwrite it blindly. Use a supported conditional-write/version check, or lock the relevant record, read its fresh state, compare, and update within one short transaction. A plain re-query followed by an unprotected write can still race. In Apex, FOR UPDATE can support that local critical section, but its locks are released by a callout; do not assume a lock protects a read-callout-write sequence. Record conflicts for review rather than treating every mismatch as a retryable technical error.

## 05 · Contract only after the transition is proven

> 🎬 ЭКРАН. Раздел «Contract only after the transition is proven». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Contract means retiring the obsolete path after consumers and data are ready. Removing a field, tightening validation, or withdrawing an old API shape can be difficult to reverse. Require explicit evidence that no supported user or integration still depends on it. A code rollback restores an earlier application revision where possible. It does not automatically restore overwritten values, recreate deleted records, or undo remote reservations. Data recovery needs its own source, identity mapping, conflict rules, and verification. Keep the previous compatible application path available long enough to make the planned rollback realistic.
