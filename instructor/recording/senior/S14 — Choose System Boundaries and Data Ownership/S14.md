Northstar uses Salesforce for customer interactions, a dealer management system for workshop operations, and a stock service for vehicle availability. A system of record is the authoritative source for a particular fact. It does not have to own every field about an entity. Salesforce may own the requested appointment while the scheduling system owns the confirmed workshop slot. Make ownership precise at the field or decision level. If both systems can independently declare the same slot reserved, a conflict policy is required. Copying the value into Salesforce does not transfer authority. ## 03 · Match the pattern to the business promise

> 🎬 ЭКРАН. Раздел «Match the pattern to the business promise». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A synchronous request asks another system for an answer while the caller waits. It fits a decision that requires a current authoritative result, but introduces a dependency into the user's critical path. An asynchronous message decouples timing, but the interface must communicate pending work and eventual outcomes. Batch synchronization moves a set of changes periodically; it can suit information whose freshness tolerance is larger. Virtual access reads information without necessarily maintaining a full local copy. It can reduce duplication, but availability, query support, performance, authorization, and product licensing must fit the use case. It is not automatically simpler just because less data is stored locally.

## 05 · Keep the first implementation narrow

Begin with one field-level ownership map and one complete business journey. A small mock service can return Available, Unavailable, Timeout, and an existing reservation for a repeated key. This tests the application's reaction without requiring a real DMS or an industry product license. Measure user-visible wait for synchronous dependencies and pending-work age for asynchronous ones. Count unresolved mismatches in reconciliation. These metrics answer different questions; a low API error count can coexist with many appointments stuck Pending because a consumer stopped processing.
