## 02 · A contract includes meaning as well as field names

> 🎬 ЭКРАН. Раздел «A contract includes meaning as well as field names». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

The scheduling provider returns a reservation reference, a status, and a start time. Northstar's consumer expects the reference to identify one stable reservation and the status to distinguish Pending from Confirmed. A contract describes request and response shape, required fields, valid values, identity, error behavior, and the meaning of those values. A response can remain valid JSON while breaking the consumer. Renaming reservationId, changing a timestamp interpretation, returning a new status, or making an optional input required can all matter. A successful HTTP status alone is therefore not an adequate compatibility test.

## 04 · Place each check at the cheapest useful boundary

> 🎬 ЭКРАН. Раздел «Place each check at the cheapest useful boundary». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Unit tests can exercise status mapping, required-field validation, and error classification without a network. An Apex HttpCalloutMock lets code receive controlled HTTP responses in tests. These checks are fast and repeatable, but the mock represents what you believe the provider does, not independent proof of the provider's current behavior. Contract verification compares that expectation with an agreed provider contract or a controlled provider environment. Integration tests check authentication, endpoint configuration, serialization, and interactions across the boundary. A focused UI smoke test verifies that Anna sees the correct user-facing state for one important journey. Acceptance checks confirm the business outcome under representative permissions.

## 05 · Make the test report honest and actionable

> 🎬 ЭКРАН. Раздел «Make the test report honest and actionable». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Report what ran, against which revision and environment, with which contract version, and what was mocked. A test named 'full booking integration' should not secretly stop at a mocked provider acknowledgment. Separate tests that passed from tests that were planned but could not run because credentials or a supported environment were unavailable. For the lesson, use the supplied payloads to test a pure mapper or an Apex mock-based adapter in a training environment. You can prove that AwaitingApproval stays Pending in the user model if that is the approved mapping. You cannot prove real provider compatibility until the provider contract and behavior are verified.
