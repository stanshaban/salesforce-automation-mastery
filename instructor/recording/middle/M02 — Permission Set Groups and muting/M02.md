## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A permission set is a reusable bundle of grants. A permission set group combines several bundles for a working persona, such as Northstar sales coordinator. Muting adjusts permissions contributed by that particular group. It does not place a universal deny on the user, and it does not rewrite the original permission set that another group may reuse. Imagine a VIN Maintenance permission set that grants Edit on Vehicle__c.VIN__c. The Data Steward group needs the grant. The Sales Coordinator group also includes this reusable permission set but mutes VIN editing. A user receiving only the coordinator group should not gain that edit permission through it. If the same user also receives VIN Maintenance directly, the independent grant remains.
