## 02 · Understand the mechanism

A feature can have passing unit tests in every layer while its combined path fails. The LWC may submit the wrong key, the service may enqueue work twice, or the worker may save a result that the UI never reloads. End-to-end verification follows the actual user intention across boundaries and checks the final business state, not merely each method's isolated return value. For Northstar, the path is Anna's request, authorized vehicle lookup, durable warranty request, background attempt, provider classification, persisted outcome, and visible UI state. The provider can remain mocked for the required course exercise. Clearly label that boundary: the test verifies your application against controlled responses, not real provider authentication, network behavior, or production throughput.
