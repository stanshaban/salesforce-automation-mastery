## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

LWC manages component instances. A lifecycle hook is a method the framework calls at a particular stage, such as construction, connection to the document, rendering, or disconnection. The lifecycle concerns the instance, not a single Salesforce record save. A component may render many times as its state or inputs change, and an attached instance may later be removed and reinserted. Use constructor for minimal initialization after super, not for querying child elements. connectedCallback is a place to begin work that requires attachment, but it can run again if the instance is reinserted. renderedCallback runs after rendering and can run repeatedly; changing reactive data there can schedule another render and create a loop. disconnectedCallback is where owned external resources often need cleanup.
