When Anna says that a warranty check failed, a developer needs to locate one business request and follow its attempts. A correlation ID connects diagnostic events belonging to the same operation. The request key from M12 can serve this role within the exercise. Each retry additionally has an attempt number and potentially a new Queueable job ID. These values answer different questions and should not replace one another. A useful diagnostic event records what stage was reached, when it happened, the outcome category, and a safe error code. It need not contain the full request body, customer details, credentials, or raw provider response. Log enough to distinguish a malformed response from an expired credential or rejected business input, while keeping sensitive data out of routine evidence.
