## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A Salesforce save can run several layers of validation and automation. Some automation changes the same or related records, causing additional processing. Order of execution is the documented sequence of these stages; it is not simply 'Flow always before Apex' or 'one click means one trigger execution.' Use the current sequence and your actual configured automation when investigating a repeated effect. Recursion is re-entry into a process caused by its own or related changes. Idempotency is a different property: repeating the same business operation does not create an additional business result. A recursion guard can reduce repeated work inside one transaction while doing nothing against a later API retry, a second Queueable transaction, or another user's concurrent request.
