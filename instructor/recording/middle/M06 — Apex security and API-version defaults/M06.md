## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Apex security questions become easier when you name two separate decisions. The class sharing declaration describes record-sharing behavior in the relevant execution context. A database operation's access mode determines whether it enforces user-level permissions or deliberately runs with elevated behavior. Saying only 'this class is with sharing' does not explain every field or object check. Defaults are versioned. In API 67.0 and later, classes without an explicit sharing declaration default to with sharing, and database operations default to user mode. In older versions, omission of a sharing declaration preserves the current sharing context rather than being a synonym for an explicit without sharing declaration; older database operations default to system mode. Read the current reference when migrating an existing class.
