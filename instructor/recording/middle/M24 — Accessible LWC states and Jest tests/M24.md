## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

An accessible component communicates state and supports operation without relying only on a mouse or color. A spinner needs meaningful context, an error needs understandable text, and a selectable row needs a keyboard-operable control. Use appropriate Lightning base components and semantic HTML before inventing custom interaction patterns. A visually attractive card can still be unusable when focus disappears after an update. Jest runs LWC unit tests locally. The tests create a component instance, supply controlled inputs or mocks, perform an interaction, and assert rendered output or dispatched events. They do not deploy to Salesforce or verify live object permissions. Mocking a successful Apex response does not prove that the actual Apex method returns that response for a restricted user.
