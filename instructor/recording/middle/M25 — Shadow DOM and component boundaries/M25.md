## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Shadow DOM defines an encapsulated internal tree for a component. The component's markup is not a public collection of elements for unrelated code to manipulate. LWC's platform implementation can differ between supported rendering modes and releases, but the design principle remains: interact through public properties, methods, events, and supported styling mechanisms rather than depending on another component's private DOM. Within a shadow-rendered LWC, this.template.querySelector accesses elements owned by that component. A document-level selector is not the correct way to find a child's private input. Timing matters too: an element may not exist before rendering or while a conditional template branch is absent. A null query result can be expected state, not a reason to bypass encapsulation.
