## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A pull request is a review boundary: it presents a proposed change, its reason, and evidence that helps another person assess it. A useful description begins with a concrete trigger and resulting behavior. For Northstar, 'repeated warranty submissions now return the existing request' is more informative than a list of files or a claim that the integration was improved. Continuous integration runs repeatable checks when code changes. Formatting, static analysis, local JavaScript tests, and metadata structure checks can run without a Salesforce org. Apex execution and deployment validation require an appropriate org and authentication. State which checks actually ran. A green repository workflow does not mean Apex passed if no org was connected.
