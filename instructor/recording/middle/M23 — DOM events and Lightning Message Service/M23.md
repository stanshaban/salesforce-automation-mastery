## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

A child component should not reach into its parent's internal state. It can receive input through @api and announce an interaction through a DOM CustomEvent. The parent handles that event and decides what to do. This makes the child reusable: a visit row can announce a selected record without knowing whether the parent opens a panel, navigates, or updates a filter. Lightning Message Service communicates across supported component regions in a Lightning page or application. It can connect components without a convenient common parent, including supported Aura or Visualforce integration points. A message channel defines the shared contract. LMS is a client-side application communication mechanism, not the server event bus used by Platform Events.
