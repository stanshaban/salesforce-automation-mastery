## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

An external ID identifies a Salesforce record using a key from another system. It lets an integration find or upsert the same record without first knowing its Salesforce Id. Upsert means create when there is no matching record and update when there is one. It is useful for synchronization, but it does not by itself make every downstream side effect exactly once. An idempotency key identifies a business operation. The same request repeated after a timeout should return the existing result or safely continue that operation. The key must have a defined scope and payload meaning. Reusing WARRANTY-100 for a different vehicle should be a conflict, not a quiet overwrite of the original customer's request.
