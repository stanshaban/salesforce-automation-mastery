## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

SOQL queries records from a known object using structured fields and filters. It suits a request such as 'show Confirmed test drives scheduled tomorrow.' SOSL searches text across supported searchable fields and can return results from multiple object types. It suits 'find the customer named Irina across Contact, Lead, and Account.' The decision starts with the question, not with which language has fewer characters. A child-to-parent SOQL relationship traverses a lookup using its relationship name. In the starter, Test_Drive__c.Customer__c points to Contact and Vehicle__c points to Vehicle__c, so expressions such as Customer__r.Name and Vehicle__r.Model__c provide related fields. These optional lookups may be null; the UI should not assume every row has a parent record.
