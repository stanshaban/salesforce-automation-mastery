## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

Batch Apex separates selection from processing. The start method defines the dataset, execute receives a scope of records, and finish performs final coordination. Each execute invocation is a separate transaction with its own applicable limits. The job is therefore not one atomic transaction: a failure in a later scope does not automatically undo records committed by an earlier successful scope. Scope size is a workload decision. Smaller scopes can reduce work and failure impact per transaction but increase transaction overhead. Larger scopes can be efficient until queries, writes, CPU, heap, or downstream automation make them unsafe. Estimate those costs from the actual operation rather than selecting 200 because it appears in an example. A scope also does not guarantee the order in which records are processed.
