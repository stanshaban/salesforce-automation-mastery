## 02 · Understand the mechanism

> 🎬 ЭКРАН. Раздел «Understand the mechanism». Продолжай показ подготовленного примера. Выдели входные данные и решение именно этого раздела. Не прокручивай целый урок вместо демонстрации. Если это аналитическое упражнение, заполняй его рабочую таблицу по одному решению.

The working tree contains the files currently checked out. The index, often called staging, records the content prepared for the next commit. A local branch points to a commit in your repository. A remote-tracking reference such as origin/main records the last fetched state of the remote branch; it is not a live view that updates itself whenever someone pushes. git fetch downloads objects and updates the relevant remote-tracking references without automatically integrating them into your current branch. git pull performs a fetch followed by an integration strategy, such as merge or rebase, according to options and configuration. Before pulling, know which branch you are on, whether the working tree is clean, and which integration behavior is intended.
