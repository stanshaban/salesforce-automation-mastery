Prepare a small dataset and a read-only action that can be tested without AI. An action is a concrete operation the agent may invoke. Its implementation is code or Flow rather than free-form generated text. SAM Demo Slot Catalog reads one visible vehicle by exact model and returns two deliberately simplified times: the next UTC calendar date at 10:00 and 14:00 UTC, each lasting 30 minutes. It does not query a real dealer calendar. The booking Flow separately checks whether the selected demo key is already claimed.
