Use the verified agent version from ordinary Lightning. A draft is editable. Commit Version fixes a version for review and Activate makes it available for use. Access to a particular Employee Agent is configured separately from permissions to its data and actions. Even the person who built an agent may need its explicit Agent Access assignment.
