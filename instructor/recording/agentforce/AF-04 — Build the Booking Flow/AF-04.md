Build an automation that accepts only a slot returned by the catalog and creates a controlled record. A Flow is a sequence of Salesforce operations and decisions. An Autolaunched Flow runs without an input screen: the agent supplies values and receives outputs. This Flow validates the customer, reloads the slot catalog, and creates the Test Drive. Validation belongs inside the automation, so a model-invented key cannot become an arbitrary appointment date. The unique Booking Key remains the final duplicate barrier in this teaching model.

## 02 · Create the Flow and variables

Setup → Flows → New Flow → Autolaunched Flow (No Trigger). Label it SAM Book Demo Test Drive, API SAM_Book_Demo_Test_Drive. Add Text input variables model, slotKey, contactId with Available for input. Add Text outputs resultCode, resultMessage, testDriveId with Available for output. Add an internal Date/Time selectedStart. Keep user-context execution; do not select System Context Without Sharing.
